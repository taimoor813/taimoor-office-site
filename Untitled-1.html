Math & Trigonometry

  • SUM: Adds numbers in a range.
  • ROUND: Rounds a number to a specified number of digits.
  • ABS: Returns absolute value.
  • POWER: Raises to a power.

Text Functions

  • LEFT: Returns first characters of text.
  • CONCAT: Joins multiple strings.
  • LEN: Length of text.
  • UPPER: Converts to uppercase.

Logical Functions

  • IF: Returns one value if TRUE, another if FALSE.
  • AND: TRUE if all are TRUE.
  • OR: TRUE if any is TRUE.
  • NOT: Reverses the logic.

Date & Time Functions

  • TODAY: Current date.
  • NOW: Current date and time.
  • DATEDIF: Difference between dates.

Lookup & Reference

  • VLOOKUP: Vertical lookup.
  • INDEX: Returns value by position.
  • MATCH: Returns position of item.
  • XLOOKUP: Modern lookup function.
