Excel Formulas & MS Word Shortcut Keys

Excel Formulas (Sample)

  • SUM: Adds all numbers in a range. Example: =SUM(A1:A10)
  • IF: Returns value if TRUE, else value if FALSE. Example: =IF(A1>5, 'Yes', 'No')
  • VLOOKUP: Looks up a value vertically in a table. Example: =VLOOKUP(lookup_value, table_array, col_index, FALSE)
  • INDEX: Returns the value of a cell at intersection of row and column. Example: =INDEX(A1:C3, 2, 3)
  • MATCH: Returns position of a lookup value. Example: =MATCH(50, A1:A10, 0)
  • CONCAT: Joins multiple text strings. Example: =CONCAT(A1, \" \", B1)
  • TODAY: Returns the current date.
  • LEN: Returns length of text. Example: =LEN(A1)
  • ROUND: Rounds a number to specified digits. Example: =ROUND(A1, 2)

MS Word Shortcut Keys (Common)

  • Ctrl + C: Copy selected text.
  • Ctrl + V: Paste copied text.
  • Ctrl + X: Cut selected text.
  • Ctrl + Z: Undo last action.
  • Ctrl + Y: Redo last undone action.
  • Ctrl + B: Bold selected text.
  • Ctrl + I: Italicize selected text.
  • Ctrl + U: Underline selected text.
  • Ctrl + S: Save document.
  • Ctrl + P: Print document.
  • Ctrl + A: Select all text.
